Selected Work

Jan 2025 — Now Gainesville, FL
Software Engineer
University of Florida — IFAS
  • Built the inference pipeline for a multi-camera CNN–LSTM leaf-wetness detection system in PyTorch — ingests streams from field cameras, runs batched GPU inference, writes scored outputs to Postgres. Work contributed to a peer-reviewed publication in Journal of Biosystems Engineering.
  • Cut training time per epoch ~20% by moving image decode + crop + normalize off the Python path into a small C++ extension and overlapping I/O with compute via a prefetching DataLoader.
  • Stood up a FastAPI + Postgres + Redis service exposing model predictions, run metadata, and per-experiment metrics over REST with versioned schemas — so the lab can compare runs apples-to-apples instead of digging through notebooks.
  • Built a Kafka-backed job queue for parallel multi-camera inference on Kubernetes; instrumented Prometheus + Grafana on queue depth, worker liveness, and inference latency. Cut wall-clock on full-day batch runs from hours to ~1 hour.
  • Designed the React dashboard ~15 lab members use day-to-day to monitor runs, training curves, and predictions.
Stack Python · PyTorch · C++ · FastAPI · Kafka · Postgres · Redis · Kubernetes · Prometheus · React
